# 02 — Typography (v1.1 LOCKED)

## Families (max 2)

- **Inter** — nav, headings, body, titles, buttons, labels, contact.
- **JetBrains Mono** — code snippets, terminal elements, technical labels, section identifiers.

Load via `index.html` (Google Fonts, `display=swap`, preconnect). System fallbacks required.

## Scale

| Element | Desktop | Mobile | Weight |
|---|---|---|---|
| Hero H1 | 64px | 42px | 800 |
| Section H2 | 36px | 28px | 750–800 |
| Card H3 | 20px | 18px | 700 |
| Lead | 17px | 16px | 400 |
| Body | 15px | 14px | 400 |
| Small | 13px | 12px | 500 |
| Section label | 11px | 11px | 700, uppercase, +0.12em |

## Line height / tracking

- H1: 1.08 desktop / 1.12 mobile, `-0.04em`.
- H2: 1.18–1.2, `-0.03em`.
- H3: 1.3. Lead: 1.6–1.65. Body: 1.65–1.7. Small: 1.5. Label: 1.4.
- Body: normal tracking. Reading width 60–75ch.

## Rules

- One accent-colored word per heading max — never whole headings.
- Never shrink body below scale. Strong headings, medium labels.
- Future type changes (new family, scale shift) → proposal + minor bump.
