# Proposals — future design / UX / structure changes

> Room for updates lives HERE. Never edit `01–09` directly — propose first.

## Template

Copy for each idea: `proposals/YYYY-MM-DD-<slug>.md`

```md
# Proposal: <title>
- Date: YYYY-MM-DD
- Status: DRAFT | ACCEPTED | APPLIED | REJECTED
- Affects: (tokens / component / section / layout / motion / content)
- Version bump: patch | minor | major

## Problem / opportunity
## Proposed change (with swatches, measurements, or wireframe notes)
## Light + dark impact
## Responsive + a11y impact
## Alternatives considered
## Decision
```

## Pipeline

`DRAFT → ACCEPTED → APPLIED` (then CHANGELOG entry + version bump + code PR link).
