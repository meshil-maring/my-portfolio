# 03 — Spacing (v1.0 LOCKED)

4px base. Compact, premium, no dead gaps. No section gets `min-h-100vh` by default.

## Scale

4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64 — icon align → major separation.

## Responsive values

| Element | Desktop | Tablet | Mobile |
|---|---|---|---|
| Page gutter | 48px | 32px | 20px |
| Header height | 72px | 68px | 64px |
| Hero top pad | 52px | 44px | 40px |
| Hero bottom pad | 48px | 40px | 36px |
| Section Y pad | 40px | 34px | 28px |
| Heading→content | 20px | 18px | 16px |
| Card padding | 20px | 18px | 16px |
| Card gap | 16px | 14px | 12px |
| Button X pad | 20px | 18px | 16px |

## Hero micro-spacing

Badge→intro 24px; intro→heading 12px; heading→role 16px; role→desc 12–16px; desc→CTA 20px; CTA gap 8–12px.

## Rules

Heading-to-desc gap < gap between sections. Hero-to-first-section stays tight. Uniform card gaps; smaller on mobile. Larger gaps only for real visual transitions.
