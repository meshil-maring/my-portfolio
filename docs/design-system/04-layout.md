# 04 — Grid & Layout (v1.1 LOCKED)

## Breakpoints

- Desktop: max 1160px, 12 cols, 48px gutter, 16px card gap.
- Tablet: 8 cols, 32px gutter, 14px gap. Simplify multi-cols.
- Mobile: 4 cols, 20px gutter, 12px gap. Stack; collapsible nav; touch-size targets.

## Rules

- One shared `Container` (max 1160px + responsive gutters). All section headings share left alignment.
- Project cards on one consistent grid. No gratuitous asymmetry.
- Text wraps; images proportional; test 375 / 768 / 1024 / 1440. No horizontal scroll.
- Layout/structure changes (new breakpoint, new grid, new page type) → proposal. New page type = minor bump.
