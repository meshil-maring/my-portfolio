# 01 – Prerequisites

## Purpose
What a new contributor needs before running the app.

## Required
- Node.js LTS (≥ 20.x) — check with `node -v`
- npm (ships with Node) or pnpm/yarn — project uses **npm** by default
- Git + GitHub access to `meshil-maring/my-portfolio`
- VS Code (recommended) + extensions:
  - ESLint, Prettier, Tailwind CSS IntelliSense, Error Lens

## Verify
```bash
node -v
npm -v
git --version
```
