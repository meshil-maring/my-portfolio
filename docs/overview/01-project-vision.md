# 01 – Project Vision

## Purpose
Single-page / multi-section developer portfolio to showcase Meshil Maring's work, skills, and contact. Fast, accessible, responsive, SEO-friendly.

## Goals
- Load fast (Lighthouse performance ≥ 90)
- Fully responsive (mobile → desktop)
- Accessible (WCAG 2.1 AA basics: focus states, contrast, semantic HTML)
- Easy to extend (projects, blogs, experience as data)

## Target audience
Recruiters, clients, collaborators, hiring managers.

## Planned sections (v1)
1. Hero (name, role, CTA, socials)
2. About
3. Skills / Tech stack
4. Projects (featured + grid)
5. Experience / Timeline
6. Contact (form + links)
7. Footer

## Non-goals (v1)
- No backend / CMS (static data in `src/data/`)
- No auth, no i18n

## Success checklist
- [ ] Deployed on Vercel/Netlify/GitHub Pages
- [ ] Custom domain (optional)
- [ ] Meta + OG tags
- [ ] 404 route
